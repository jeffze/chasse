Conseils & rappels

  • Sécurité Informe quelqu'un de ton spot et de ton heure de retour. Porte ton dossard orange selon la réglementation.
  • Orientation Télécharge les cartes hors-ligne (Google Maps, Avenza) avant de partir. Emporte une boussole.
  • Batterie Mode avion + GPS lorsqu'immobile; banque d'alimentation chargée.
  • Météo Vérifie la météo et le vent avant de perdre le réseau. Prévoyez des vêtements secs pour le retour.

Mentions

Cet outil reste local (LocalStorage). Le calcul solaire utilise une implémentation embarquée basée sur les formules NOAA (approx.). Les heures affichées sont indicatives; respecte toujours la réglementation officielle du territoire de chasse.

Bienvenue sur votre Compagnon de Chasse ! 🦌

Cette application est conçue pour être votre outil tout-en-un sur le terrain. Son plus grand avantage : tout fonctionne sans connexion internet. Vos données restent sur votre téléphone, en toute confidentialité.

🧭 Tour d'horizon des fonctionnalités

☀️ Tableau de Bord

L'écran principal est composé de panneaux dépliables pour garder l'interface claire. Touchez le titre d'une section pour afficher ou masquer son contenu. Les informations les plus importantes (Actions, Soleil, Météo) sont ouvertes par défaut.

🩸 Recherche de Gibier

Une fonction essentielle après un tir. Dépliez ce panneau, cliquez sur "Démarrer" pour marquer votre position de tir, puis utilisez le bouton "Marquer une trace" à chaque indice trouvé. L'application crée une piste numérique dans vos waypoints, avec la distance et la direction entre chaque point pour ne jamais vous perdre.

📜 Permis (Nouveau !)

Conservez une copie hors-ligne de vos permis. Pour chaque permis, vous pouvez ajouter plusieurs périodes de validité pour gérer les différentes zones et types d'armes, et même attacher une photo ou un PDF de votre permis officiel pour l'avoir toujours sous la main.

📝 Journal

Enregistrez vos observations en un clic. L'application sauvegarde automatiquement l'heure, votre position GPS exacte et la météo (température et vent) à ce moment précis. C'est idéal pour analyser vos sorties plus tard.

📍 Waypoints (Points d'intérêt)

Enregistrez des lieux importants : votre voiture, une souille, un mirador... L'icône de vent à côté de chaque waypoint est un atout majeur :

  • Vent BON : Votre odeur s'éloigne du waypoint.
  • Vent MAUVAIS : Votre odeur est poussée vers le waypoint.

🔄 Échange de Données : Import & Export

Vous pouvez maintenant échanger des informations spécifiques (waypoints, listes d'équipement, permis, menus) avec vos partenaires de chasse. Chaque onglet possède ses propres boutons "Importer" et "Exporter".

Créer vos propres fichiers CSV

Pour préparer votre chasse à l'avance sur un ordinateur, vous pouvez créer des fichiers CSV avec un simple éditeur de texte (Bloc-notes) ou un tableur (Excel). Voici les formats à respecter :

Format pour les Waypoints (.csv)

La première ligne doit être l'en-tête exact. La colonne "notes" est optionnelle.

name,latitude,longitude,notes
Mirador Principal,47.07253,-72.23841,"Belle vue sur la coulée"
Saline #1,47.07111,-72.23999,
Format pour les Blocs d'Équipement (.csv)

Un seul item par ligne. Pas d'en-tête nécessaire.

🆘 Aide & Fonctions Utilitaires

L'onglet "Aide" regroupe toutes les fonctions de maintenance :

  • Exporter des Données : Permet d'exporter des modules spécifiques (waypoints, permis, etc.).
  • Exporter la sauvegarde complète : Crée un fichier JSON unique avec TOUTES vos données. C'est la meilleure façon de faire une sauvegarde de sécurité.
  • Importer un fichier : Permet de charger n'importe quel fichier exporté par l'application.
  • Maintenance : Contient le bouton pour réinitialiser complètement l'application.
